# Korean Plain v0.1.0

첫 공개 버전은 Claude Code용 `Korean Plain` output style과 이를 설치하는 marketplace manifest를 제공합니다. 읽기 쉬운 한국어를 쓰되 사실, 불확실성, 검증 경계를 보존하는 것이 목표입니다.

## 포함된 것

- output style 하나를 담은 plugin
- 합성 fixture와 독립 결정적 평가기
- 격리 설치 검증과 공개 문서

skill, agent, hook, MCP server, 실행 파일, 런타임 의존성은 포함하지 않습니다. Claude Code 2.1.223에서 검증했습니다. 배포물은 Git tag가 가리키는 저장소 tree이며 별도의 업로드 release asset은 없습니다.

설치와 제거 방법은 [README](../../README.md), 평가 경계는 [EVALUATION](../EVALUATION.md)을 참고하세요.

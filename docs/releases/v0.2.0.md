# Korean Plain v0.2.0

플러그인이 켜져 있는 동안 `Korean Plain`이 자동으로 적용됩니다. 설치한 뒤 `/config`에서 따로 고르지 않아도 됩니다.

## 바뀐 것

- style이 `force-for-plugin: true`를 사용합니다. 플러그인이 켜져 있으면 `/config`에서 고른 output style보다 우선합니다.
- 끄는 방법은 `claude plugin disable`입니다. 플러그인을 끄면 `/config`에 남아 있던 값이 다시 적용됩니다.
- style 본문에서 호응이 맞지 않는 문장을 고치고, 불확실성을 밝히라는 지침에 대상 범위를 명시했습니다.
- 평가 gate가 지어낸 수치와 한 글자 패턴을 걸러내도록 고쳤습니다.

`/config`의 Output style 항목은 저장된 설정값을 보여 줍니다. 플러그인이 켜져 있으면 화면에 보이는 값과 실제 적용이 다를 수 있습니다.

skill, agent, hook, MCP server, 실행 파일, 런타임 의존성은 포함하지 않습니다. Claude Code 2.1.228에서 검증했습니다. 배포물은 Git tag가 가리키는 저장소 tree이며 별도의 업로드 release asset은 없습니다.
